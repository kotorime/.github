# .github

組織 `kotorime` の共通ファイル。`profile/README.md` が、組織のページ（<https://github.com/kotorime>）の冒頭に表示される。

- `profile/kotori-icon.svg` / `kotori-icon.png`: 組織のアイコン。Android 版のランチャーアイコン（`ic_launcher_foreground.xml`）と同じ図形。
  組織のアイコンそのものは、GitHub の設定画面（Settings → Profile picture）から `kotori-icon.png` をアップロードして設定する
- 公開の状況が変わったら、`profile/README.md` の「公開の状況」を直す（紹介サイトの「入手」の節も同じ）
