# Kotori日本語入力

フリックで打つ日本語キーボードです。Android と iOS で動きます。

- **拡張フリック** — キーを押したまま指を曲げると、濁音や拗音まで打てます。「か」のキーから指を離さずに「きょう」まで打てます
- **端末の中だけで変換** — かな漢字変換の辞書も、文脈を見て候補を選び直す「AI 超変換」のモデルも、アプリに入っています
- **打ったことばを外へ送らない** — 入力した内容を、運営や第三者のサーバーへ送りません。広告と、利用状況の分析もありません
- **着替** — キーボードの背景に写真や色を敷けます。キーの形、濃さ、すきま、高さ、位置も変えられます

くわしくは [紹介サイト](https://kotorime.github.io/kotori-website/) をご覧ください。
